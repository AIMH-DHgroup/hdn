Collegamento a SVN
==================

Il repository SVN che utilizziamo si trova sul server Dante2, al seguente indirizzo: http://dante2.isti.cnr.it/svn/DanteRepo1/hdnDevelop. 
Per accedere al repository è necessario inserire nome utente e password.

1. Scaricare da SVN la cartella del progetto: ``svn checkout http://dante2.isti.cnr.it/svn/DanteRepo1/hdnDevelop``
2. Entrare nella directory: ``cd hdnDevelop``
